# M291-ky

## À propos de moi

Je m'appelle **Kevin Youssef** et je suis actuellement en **3ème année de Médiamatic**.

Je suis **designer depuis 8 ans** et j'ai ma **freelance depuis 6 ans**. À travers ce projet, je souhaite créer un site qui présente mon travail et mes différentes créations.

## Objectif du projet

L'objectif de ce projet est de créer **mon site de portfolio de design**.

Le site permettra aux visiteurs de :

- Découvrir mes créations
- Voir différents projets de design
- En apprendre davantage sur mon travail
- Me contacter grâce à un **formulaire de contact**

## Ce que je souhaite apprendre

Avec ce projet, je souhaite principalement :

- Comprendre **comment fonctionne le code**
- Apprendre le *vocabulaire lié au développement web*
- Comprendre comment fonctionne un site internet
- Apprendre à mieux utiliser le code pour réaliser mes propres projets

## Technologies utilisées

Pour réaliser ce projet, j'utilise les technologies suivantes :

- HTML
- CSS
- JavaScript
